# Ключ подписи APK

`release.keystore` — постоянный релизный ключ Horizons RP. Он лежит в репозитории
специально: благодаря ему у всех сборок одинаковая подпись, поэтому

* новая версия ставится поверх старой (не нужно удалять приложение);
* отпечаток SHA-1 не меняется, и Google OAuth для Android продолжает работать.

```
alias:      rpigra
store/key пароль: rpigra2026
SHA-1:      1C:0A:C6:72:85:AF:9E:5C:28:81:F1:67:AE:26:3E:96:09:EE:74:C2
SHA-256:    2A:23:CE:51:EB:17:DE:20:BC:8D:41:DC:45:E9:14:76:2A:E7:23:E8:A9:C1:D6:64:8E:52:85:A8:22:68:4E:3C
```

Это ключ любительской игры, не банковское приложение: пароль открытый ради простоты
сборки в GitHub Actions. Если игра пойдёт в Google Play — сгенерируй новый ключ,
положи его в secrets репозитория и замени пароли в `.github/workflows/build-apk.yml`.

Посмотреть отпечаток локально:

```bash
keytool -list -v -keystore android-keys/release.keystore -storepass rpigra2026
```
